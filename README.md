# Smart Banking & Financial Analytics System

## Project Overview

The Smart Banking & Financial Analytics System is a complete end-to-end SQL project designed to simulate a real-world banking database system.

This project was built to learn and apply SQL from beginner to advanced level by implementing practical banking operations, financial analytics, transaction management, and database optimization concepts.

The project covers:

- Database Design
- SQL Queries
- Joins
- Subqueries
- CTEs
- Window Functions
- Stored Procedures
- Triggers
- Transactions
- Views
- Materialized Views
- Indexing
- Query Optimization
- Banking Analytics
- Fraud Detection Queries
